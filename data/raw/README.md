# Raw data

Nothing in here is edited by hand and nothing in here is tracked by git. Every
file must be re-downloadable from the note below, or re-requestable from the
Estate Office. If a file cannot be reproduced, it does not belong here.

    footprints/     OpenStreetMap extract and Google Open Buildings tiles for
                    the campus bounding box
    imagery/        sub-metre satellite imagery, with the acquisition date of
                    every scene recorded - FR-3 validation needs a dated image
    irradiance/     PVGIS TMY and NASA POWER responses, cached as JSON by
                    btp_solar.fr1_data
    estate_office/  single-line diagram, transformer schedule, feeder layout,
                    consumption records. Record the date each item was
                    requested and received; the specification makes the delay a
                    named project risk.

Record the download date and the exact query for each item in
docs/decisions.md as you go. A number whose provenance is not written down at
the time it is fetched is a number that gets argued about in November.
